# Бот «Квартиры в Болгарии» (русский + иврит)

## Что умеет

**Клиенты**
- выбирают язык: русский или иврит;
- открывают канал на своём языке;
- «Подобрать квартиру»: город → тип → бюджет → телефон, и вам приходит заявка;
- «Связаться с менеджером»: вопрос приходит вам, ваш ответ (Reply) бот пересылает клиенту;
- кнопка «Узнать подробнее» под каждым объявлением ведёт в бот, и вам приходит заявка с номером объекта.

**Админ (вы)**
- `/add`: добавить объект. Бот задаёт вопросы по шагам, показывает предпросмотр и публикует сразу в оба канала;
- `/list`: список объектов;
- `/sold 5`: объект №5 продан или сдан, в каналах появляется пометка «❌ ПРОДАНО / ❌ נמכר»;
- `/active 5`: вернуть объект в продажу;
- `/delete 5`: удалить объявление из каналов;
- `/cancel`: отменить текущее действие;
- `/myid`: узнать свой Telegram ID.

## Подготовка в Telegram

1. **Бот**: напишите @BotFather, отправьте `/newbot`, задайте имя и юзернейм (например `KvartiryBolgariaBot`) и скопируйте **токен**.
2. **Каналы**: создайте два публичных канала, например `@KvartiryBolgaria` (русский) и `@DiraBulgaria` (иврит).
3. В каждом канале откройте «Администраторы», добавьте бота и дайте ему право **публиковать и редактировать сообщения**.
4. По желанию: в настройках канала откройте «Обсуждение» и привяжите группу для комментариев.

## Запуск

Нужен Python 3.10 или новее.

```bash
pip install -r requirements.txt
cp .env.example .env      # затем откройте .env и впишите токен и каналы
python bot.py
```

Чтобы узнать свой ID, запустите бота, напишите ему `/myid` и впишите число в `ADMIN_IDS` в файле `.env`. После этого перезапустите бота.

## Чтобы бот работал круглосуточно (VPS, Ubuntu)

```bash
sudo apt update && sudo apt install -y python3-pip python3-venv
cd /opt && sudo mkdir realty-bot && sudo chown $USER realty-bot && cd realty-bot
# скопируйте сюда файлы бота и .env
python3 -m venv venv && venv/bin/pip install -r requirements.txt
```

Создайте файл `/etc/systemd/system/realty-bot.service`:

```ini
[Unit]
Description=Realty bot
After=network.target

[Service]
WorkingDirectory=/opt/realty-bot
ExecStart=/opt/realty-bot/venv/bin/python bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now realty-bot
sudo journalctl -u realty-bot -f    # смотреть логи
```

## Как менять тексты, города и типы жилья

Всё лежит в файле `texts.py`: приветствия, кнопки, список городов и подписи в объявлениях. Редактируйте текст в кавычках и не трогайте ключи. После правок перезапустите бота.

Данные (пользователи, объекты, заявки) хранятся в файле `bot.db`. Иногда делайте его резервную копию.
